# M2 – serwer na Optiplexie (runbook)

Cel M2: Quaderno działa na Optiplexie 24/7, telefon i laptop widzą tę samą lekcję, a kopie bazy robią się same co noc.
Wszystko poniżej wpisujesz na Optiplexie (Ubuntu Server 24.04), przez SSH albo przy klawiaturze.
Każdy krok ma „oczekiwane:”. Jeśli wynik jest inny, zatrzymaj się i wklej mi go.

## 0. BIOS: włączanie po zaniku prądu (raz)

Przy starcie Della wciśnij **F2** → **Power Management** → **AC Recovery** → **Power On** → **Apply** → **Exit**.
Dzięki temu po przerwie w prądzie Optiplex sam wstanie, a Docker sam uruchomi Quaderno (`restart: unless-stopped`).

## 1. Docker i git (raz)

```bash
sudo apt update && sudo apt install -y git curl
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER      # potem wyloguj się i zaloguj ponownie
docker compose version             # oczekiwane: Docker Compose version v2.x
```

## 2. Tailscale (raz)

Tailscale daje prywatną sieć między Optiplexem, telefonem i laptopem. Nic nie wystawiamy do internetu.

```bash
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up                  # otwórz link z terminala i zaloguj się
tailscale ip -4                    # oczekiwane: adres 100.x.y.z
```

W panelu https://login.tailscale.com/admin/dns włącz **MagicDNS** i **HTTPS Certificates** (potrzebne do `tailscale serve`).
Na telefonie i laptopie zainstaluj aplikację Tailscale i zaloguj się tym samym kontem.

## 3. Kod i sekrety (raz)

```bash
git clone https://github.com/igorkotlarz1/quaderno.git ~/quaderno
cd ~/quaderno
cp .env.example .env
sed -i "s/^POSTGRES_PASSWORD=.*/POSTGRES_PASSWORD=$(openssl rand -hex 24)/" .env
chmod 600 .env
grep -c . .env                     # oczekiwane: liczba linii > 0; hasła NIE wklejaj nigdzie
```

Hasło ma same cyfry i litery a–f, więc nie psuje adresu bazy. `.env` jest w `.gitignore`, nie trafi do repo.

## 4. Start

```bash
docker compose up -d --build       # pierwszy raz kilka minut (buduje aplikację)
docker compose ps                  # oczekiwane: db (healthy), api (healthy), backup Up
curl -s localhost:8000/api/health  # oczekiwane: {"status":"ok"}
```

API słucha tylko na `127.0.0.1:8000`. Do telefonu i laptopa wystawiamy je przez Tailscale (HTTPS w Twojej sieci):

```bash
sudo tailscale serve --bg 8000
tailscale serve status             # oczekiwane: https://<nazwa-optiplexa>.<tailnet>.ts.net → http://127.0.0.1:8000
```

Zapisz ten adres `https://….ts.net`. To jest od teraz adres Quaderno.

## 5. Przenieś swoje lekcje z Artifactu (raz)

1. W Artifakcie Quaderno: **Eksport i import** → **Kopiuj JSON**.
2. Na laptopie otwórz `https://….ts.net` → **Eksport i import** → wklej JSON → **Importuj wklejony JSON**.
3. Oczekiwane: w stopce po chwili **„Zapisane na serwerze HH:MM”**.

Artifactu nie kasuj. Zostaje w użyciu, dopóki M3 (tryb offline) nie przejdzie bramki.

## 6. Bramka: telefon i laptop widzą tę samą lekcję

1. Laptop: otwórz `https://….ts.net`, wpisz `la finestra` → Enter → `okno` → Enter.
2. Poczekaj na **„Zapisane na serwerze”** w stopce.
3. Telefon (Tailscale włączony): otwórz ten sam adres. Oczekiwane: dzisiejsza lekcja z `la finestra – okno`.
4. Telefon: dopisz `il tavolo` z pustym polskim (NULL).
5. Laptop: przełącz się na inną kartę i wróć (albo odśwież). Oczekiwane: `il tavolo` z czerwonym „brak tłumaczenia”.

Na telefonie możesz dodać skrót: Chrome → ⋮ → **Dodaj do ekranu głównego**. Pełna aplikacja offline to M3.

## 7. Bramka: próbne odtworzenie kopii

```bash
docker compose exec backup backup.sh
# oczekiwane: backup: /backups/quaderno_2026-..._....dump (… kB)
#             backup: RESTIC_REPOSITORY is empty, off-site copy skipped   (dopóki nie ustawisz B2)
docker compose exec backup restore-test.sh
# oczekiwane: restore-test: live ... = restored ...  i na końcu  restore-test: OK
ls -lh backups/                    # pliki .dump leżą też na dysku Optiplexa
```

`restore-test.sh` odtwarza kopię do osobnej, tymczasowej bazy i ją usuwa. Twoich danych nie dotyka.
Kopia robi się sama codziennie o 3:00 (`BACKUP_HOUR` w `.env`), na dysku zostaje 14 ostatnich.

## 8. Kopie poza domem: Backblaze B2 (opcjonalnie, polecam)

1. https://www.backblaze.com/b2 → załóż konto → **Buckets** → **Create a Bucket** (prywatny), np. `quaderno-backup-<coś-losowego>`.
2. **Application Keys** → **Add a New Application Key**, tylko do tego bucketu.
3. Uzupełnij w `.env` (tylko na Optiplexie, nigdy w repo ani w czacie):

```bash
nano .env
# RESTIC_REPOSITORY=b2:<nazwa-bucketu>:quaderno
# RESTIC_PASSWORD=<wygeneruj: openssl rand -hex 24 i ZAPISZ w menedżerze haseł>
# B2_ACCOUNT_ID=<keyID>
# B2_ACCOUNT_KEY=<applicationKey>
docker compose up -d backup
docker compose exec backup backup.sh   # oczekiwane na końcu: restic snapshot sent to b2:...
```

Bez `RESTIC_PASSWORD` kopii w B2 nie da się odczytać, więc zapisz je poza Optiplexem.

## 9. Prawdziwe odtworzenie (tylko gdy coś padnie)

```bash
docker compose stop api
docker compose exec backup sh -c 'ls -1t /backups/*.dump | head -3'
docker compose exec -it backup restore.sh /backups/quaderno_RRRR-MM-DD_GGMM.dump   # wpisz YES
docker compose start api
```

## Aktualizacja do nowej wersji

```bash
cd ~/quaderno && git pull && docker compose up -d --build
```

Migracje bazy robią się same przy starcie `api`.

## Gdy coś nie działa

- `docker compose logs api --tail 50` i `docker compose logs db --tail 50`, wklej mi wynik (bez `.env`).
- Stopka pokazuje **„Brak połączenia z serwerem”**: sprawdź, czy Tailscale jest włączony na telefonie. Wpisy zostają w przeglądarce i wyślą się przy następnym połączeniu, także po zamknięciu karty. Aplikacja bez sieci w ogóle się nie otworzy, to dopiero M3.
