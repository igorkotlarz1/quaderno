# M1 – jak sprawdzić (runbook)

Cel M1: Quadernote działa jako aplikacja React + TypeScript i po imporcie Twojego eksportu wygląda tak samo jak Artifact.
Na tym etapie nie ma jeszcze serwera, więc wystarczy laptop albo Optiplex z przeglądarką.

## 1. Przygotowanie (raz)

Potrzebujesz Node.js 22 i gita.

```bash
node -v          # oczekiwane: v22.x
git clone https://github.com/igorkotlarz1/quaderno.git
cd quaderno/web
npm ci           # instaluje zależności z package-lock.json
```

## 2. Uruchom aplikację

```bash
npm run dev
```

Oczekiwane: w terminalu `Local: http://localhost:5173/`. Otwórz ten adres.
(Na Optiplexie bez ekranu: `npm run dev -- --host` i wejdź z laptopa na `http://<ip-optiplexa>:5173`.)

## 3. Sprawdź bramkę „gotowe, gdy”

1. W Artifakcie Quaderno otwórz **Eksport i import** → **Kopiuj JSON**.
2. W nowej aplikacji otwórz **Eksport i import**, wklej JSON w dolne pole, kliknij **Importuj wklejony JSON**.
3. Porównaj z Artifaktem: ta sama data, liczniki, słówka (czerwone „brak tłumaczenia” przy NULL), czasowniki z tymi samymi odkrytymi formami, pasek poziomu.
4. Przełącz lekcje w **Wszystkie lekcje** na dole i sprawdź jeszcze jedną.

Twoje dane zostają w przeglądarce (localStorage). Nic nie trafia do repo ani na serwer.

## 4. Testy automatyczne (opcjonalnie)

```bash
npm run typecheck   # oczekiwane: brak błędów
npm test            # oczekiwane: 30 passed
npx playwright install chromium   # raz
npm run e2e         # oczekiwane: 2 passed, w tym test_gate_m1
```

`test_gate_m1` robi to samo co punkt 3 automatycznie: importuje wymyślony eksport do starego pliku
(`legacy/quaderno.html`) i do nowej aplikacji i porównuje, co widać na obu stronach.
