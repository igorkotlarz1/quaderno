# M4 – Claude jednym kliknięciem (runbook)

Cel M4: „Opracuj lekcję” i „Oceń tydzień” to jeden klik zamiast kopiowania promptu, a koszt każdego wywołania widać w logu.
Każdy krok ma „oczekiwane:”. Jeśli wynik jest inny, zatrzymaj się i wklej mi go.

Potrzebne: M2 działa na Optiplexie. Klucz API z <https://console.anthropic.com> → **API keys** → **Create key**
(najlepiej osobny klucz „quadernote” i limit wydatków w **Limits**, np. 5 $ miesięcznie).

## 1. Klucz tylko w `.env` na serwerze

```bash
cd ~/quaderno && git pull
nano .env        # dopisz linię: ANTHROPIC_API_KEY=sk-ant-...   (bez spacji i cudzysłowów)
chmod 600 .env
git status --short .env
```

Oczekiwane: `git status` nic nie wypisuje (`.env` jest w `.gitignore`, nigdy nie trafia do repo).
Klucz nie wychodzi z serwera: telefon i laptop rozmawiają tylko z Twoim API, a ono z Claude.

## 2. Restart i sprawdzenie

```bash
docker compose up -d --build
curl -s localhost:8000/api/llm/status; echo
```

Oczekiwane: `"enabled":true,"fake":false`, modele `claude-haiku-5-5` (lekcja) i `claude-sonnet-5-5` (tydzień), `"calls":[]`.
Jeśli `"enabled":false`: klucz nie dotarł do kontenera; sprawdź nazwę zmiennej w `.env` i uruchom krok 2 jeszcze raz.

## 3. Bramka: jeden klik

1. Na laptopie albo telefonie otwórz dzisiejszą lekcję. Wpisz dwa nowe wiersze: `perche` z tłumaczeniem i jakieś słowo bez tłumaczenia.
2. **Uzupełnij z Claude → Opracuj lekcję.** Przycisk pokazuje „Claude pracuje…” (kilka do kilkunastu sekund).
3. Oczekiwane: komunikat w rodzaju „Claude przetłumaczył 1, poprawił akcenty: 1 · koszt 0,3 gr”, `perche` → `perché`
   z kropkowanym podkreśleniem (najedź: „Claude poprawił z: perche”), brakujące tłumaczenie uzupełnione.
4. Rozwiń **Koszty Claude**. Oczekiwane: wiersz „lekcja · haiku-5-5 · tokeny · koszt”.
5. Na serwerze: `curl -s localhost:8000/api/llm/status | head -c 400; echo`. Oczekiwane: ten sam wpis w `calls`, `"status":"ok"`.

## 4. Ocena tygodnia jednym kliknięciem (raz w tygodniu)

**Ocena tygodnia → Oceń tydzień.** Oczekiwane: „Nowa ocena poziomu zapisana · koszt …”, fiolka na górze się aktualizuje,
w **Kosztach Claude** wiersz „ocena tygodnia · sonnet-5-5”.

## Gdy coś nie działa

| Komunikat w aplikacji | Co zrobić |
|---|---|
| „Brak ANTHROPIC_API_KEY na serwerze” | krok 1 i 2 |
| „Serwer ma zły klucz ANTHROPIC_API_KEY” | klucz skasowany albo literówka: nowy klucz w konsoli, krok 1 i 2 |
| „Limit zapytań Claude API” | odczekaj minutę; jeśli wraca, sprawdź limity w konsoli |
| „Serwer nie może połączyć się z Claude API” | Optiplex nie ma internetu albo DNS: `docker compose exec api python -c "import urllib.request;print(urllib.request.urlopen('https://api.anthropic.com').status)"` |
| „Claude odmówił odpowiedzi” | rzadkie; zapisane w logu jako „odmowa”, wtedy użyj promptu ręcznie |

Koszty w aplikacji to szacunek z cennika (przelicznik ok. 4 zł/$). Dokładny rachunek: konsola Anthropic → **Usage**.
Ręczny prompt („Kopiuj prompt (ręcznie)”) działa dalej, także bez klucza.
