# M3.5 – słownik włosko-polski offline (runbook)

Cel M3.5: słowo z top 5000 wpisane w trybie samolotowym dostaje polską podpowiedź bez API, a do Claude idzie tylko to, czego słownik nie zna.
Każdy krok ma „oczekiwane:”. Jeśli wynik jest inny, zatrzymaj się i wklej mi go.

Potrzebne: M3 działa (aplikacja zainstalowana na telefonie, adres `https://….ts.net`).

## 1. Aktualizacja na Optiplexie

```bash
cd ~/quaderno && git pull && docker compose up -d --build
curl -s localhost:8000/api/lexicon/meta; echo
```

Oczekiwane: `{"loaded":false}`. Migracja `0002` założyła puste tabele `lex_lemmas`, `lex_forms` i `lex_meta`.

## 2. Zbuduj słownik (raz, potem tylko przy aktualizacji danych)

```bash
docker compose exec api python -m app.lexicon.build
```

Skrypt pobiera trzy otwarte zbiory (lista frekwencji z napisów filmowych, Morph-it!, Wikisłownik przez kaikki.org)
do `/tmp/quadernote-lexicon` w kontenerze. Dwa pierwsze sprawdza po SHA-256; gdy plik się zmienił, przerywa z komunikatem
`…changed…` i niczego nie wgrywa. Danych nie ma w repo.

Oczekiwane na końcu jedna linia w rodzaju:

```
lexicon 1a2b3c4d5e6f: 2xxxx lemmas, 1xxxxx forms; coverage top 100: …%, top 500: …%, top 1000: …%, top 2000: …%, top 5000: …%
```

Wklej mi tę linię: liczby pokrycia trafią do README zamiast szacunku. Potem sprawdzenie:

```bash
curl -s "localhost:8000/api/lexicon/lookup?q=le%20finestre" | head -c 200; echo
curl -s localhost:8000/api/lexicon/meta | head -c 300; echo
```

Oczekiwane: w pierwszym `"lemma":"finestra"` i `"gloss":"okno"`, w drugim `"loaded":true` i lista trzech źródeł.

Jeśli kaikki.org nie odpowiada albo pobieranie się urywa: uruchom drugi raz (pobrane pliki zostają w cache).
Gdy dalej nie idzie, pobierz trzy pliki na laptopie, skopiuj je do kontenera i zbuduj z folderu:
`docker compose cp ./lexdata api:/tmp/lexdata && docker compose exec api python -m app.lexicon.build --from /tmp/lexdata`
(nazwy plików: `it_50k.txt`, `morph-it_048.txt`, `wiktionary.jsonl`).

## 3. Telefon: słownik ląduje w pamięci

1. Otwórz Quadernote z siecią. W „Narzędzia” zakładka **Słownik offline**.
2. Oczekiwane: podpis „5000 najczęstszych słów, działa bez sieci”. Po rozwinięciu lista **Źródła słownika** z trzema pozycjami i licencjami.

## 4. Bramka: tryb samolotowy

1. Włącz tryb samolotowy, zamknij i otwórz aplikację.
2. W nowym wierszu wpisz `le finestre` (bez polskiego).
3. Oczekiwane: pod wierszem „słownik:” i przycisk **okno**. Pole „polski” zostaje puste, dopóki nie klikniesz.
4. Kliknij **okno**. Oczekiwane: „polski” = okno, z kropkowanym podkreśleniem (znaczy: ze słownika).
5. Dopisz `perche` (bez akcentu) i jakieś rzadkie słowo spoza słownika. Oczekiwane: `perche` dostaje podpowiedzi (np. „dlaczego”), rzadkie słowo żadnych.
6. **Słownik offline → Uzupełnij ze słownika.** Oczekiwane: komunikat „Uzupełniono 1 pozycję, dla Claude zostaje 1”.
7. **Uzupełnij z Claude → Kopiuj prompt**, wklej gdzieś. Oczekiwane: „Pozycji bez tłumaczenia: 1.” i tylko rzadkie słowo ma `"pl": null`.
8. Wyłącz tryb samolotowy. Oczekiwane: stopka wraca do „Zapisane na serwerze”, a słowa ze słownika są też na laptopie.

Bramka zaliczona, gdy kroki 3, 4 i 7 się zgadzają. Automatycznie to samo sprawdza `web/e2e/gate_m35.spec.ts` (na testowym mini-słowniku).

## Aktualizacja danych (opcjonalnie, np. raz na pół roku)

Wikisłownik się zmienia: `docker compose exec api python -m app.lexicon.build` buduje słownik od nowa, a telefon pobierze nową wersję przy następnym połączeniu (stara działa do tego czasu).
